Information on modding Vampire: The Masquerade - Bloodlines is scattered across community sites. Start with the path that matches what you want to do.

## Find and use mods

- [Browse Bloodlines mods on Nexus Mods](https://www.nexusmods.com/games/vampirebloodlines) for game mods and their download pages.
- [Browse Bloodlines mods on ModDB](https://www.moddb.com/games/vampire-the-masquerade-bloodlines) to find game mods, add-ons, files, and tutorials.
- If you use the Fashionista modlist, see its [Optional Mods](/Fashionista/OptionalMods.html) and [Fashion](/Fashionista/Fashion.html) pages for options included with that list. Check the profile-specific notes before enabling an option.

## Create or edit game content

- [Planet Vampire's Bloodlines modding forum](https://planetvampire.freeforums.net/board/7/vtm-bloodlines-modding) is a place to read community discussions and ask modding questions.
- [Compiling a custom PC model](https://www.moddb.com/games/vampire-the-masquerade-bloodlines/tutorials/compiling-a-custom-pc-model-with-ddlullus-mdl-formatter) covers one workflow for creating a character model.

## Build a Wabbajack list

The [Create your own list](/Fashionista/CreateYourOwnList.html) guide explains how Fashionista uses Mod Organizer 2, a stock game folder, Root Builder, the Unofficial Patch, and Wabbajack compile settings. It is an advanced guide based on Fashionista's setup.

If an overhaul comes as an Inno Setup `.exe`, see [Extracting mod installers](/ModdingBloodlines/ExtractingInstallers.html) for a way to inspect its files and optional components before building your MO2 mods.

## Other reference pages on this site

- [Fashionista Modlist](/Fashionista/Modlist.html) shows the list's mod load order.
- [Fashionista Files](/Fashionista/Files.html) collects links to files used by the list.
