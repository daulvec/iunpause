# Fashion screenshot checklist

Compare the [Fashionista modlist](docs/Fashionista/Modlist.md) with the [Fashion pages](docs/Fashionista/Fashion.md). Each unchecked entry below is in the modlist export but has no matching outfit entry on its clan and gender page. Add the outfit details and an in-game screenshot as you work through them. Disabled optional mods are included.

The 146 outfits already documented each have a preview image reference, and every referenced image file exists in this repository. This checklist therefore tracks **missing outfit entries and their screenshots**, not broken image files.
